\section{AC$^0$-Local CSPs: Corrected Scope}
The historical constant-distortion normalization and universal
$\mathrm{EDA}_A(F)=\Theta(n)$ claims are withdrawn as proved results.
Bounded fan-in and bounded arity do not bound aggregate output width:
$n$ independent uniform bits can be copied simultaneously by $n$
fan-in-one gates, revealing $n$ bits to an initially input-independent
observer. A normalization theorem must specify access, wiring,
aggregate capacity, output semantics and cost, and prove their
preservation. Unrestricted separation remains open.

\begin{theorem}[Restricted synchronous path broadcast]\label{thm:ac0-path-broadcast}
On a path with $n\ge1$ vertices, only the first vertex initially
receives an arbitrary bit. All other initial data are independent of
that bit. Each synchronous round uses only previous own and neighbor
states, and every vertex must output the bit. With no nonlocal
communication or input-dependent auxiliary initialization, the minimum
worst-case number of rounds is $n-1$.
\end{theorem}
\begin{proof}
By induction, each state after $t$ rounds depends only on initial
data within distance $t$. If $t<n-1$, the last vertex cannot
distinguish the two input bits, although its required output differs.
Forwarding the bit along the path attains $n-1$ rounds.
\end{proof}
This is a distributed output result, not a SAT decision lower bound
or general EntropyDepth separation. TRAP remains unproved.

\section{Beyond AC$^0$: Bounded Aggregation (Open)}
The proposed polylogarithmic distortion for bounded-aggregation
update systems is an open conjecture. Bounded per-gate aggregation
does not bound the total output width or information disclosed by
parallel gates. A valid theorem requires aggregate-capacity,
access, encoding and cost hypotheses and their preservation.
The underlying unrestricted AC$^0$ normalization is itself open.
No extension of a proved universal frontier is asserted.

# Eclipse Witness Status Uniqueness

## Status

Conditional.

## Target

\[
\boxed{
\forall k\in K_0,\ \forall S,S'\in\{\mathrm{OPEN},\mathrm{CONDITIONAL},\mathrm{PROVED}\},\
\Big(
W_0(k)\text{ certifies }S\text{ for }k
\wedge
W_0(k)\text{ certifies }S'\text{ for }k
\Big)
\Rightarrow
S=S'.
}
\]

## Role

This is the exact witness-extensionality law needed to force status uniqueness from a fixed witness assignment.

## Certification form

\[
W_0(k)\text{ certifies }S\text{ for }k
\Rightarrow
S=S_0(k).
\]

## Terminal missing object

A proof that certification by a fixed witness cannot validate two distinct statuses for the same claim.

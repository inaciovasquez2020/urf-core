# Measure-Cycle to Local Cycle-Rank Bound

Conditional.

\[
\boxed{
\mathbf{MC}\Rightarrow \mathbf{LCRB}
}
\]

\[
\mathbf{MC}:
\exists c_{k,\Delta,R}>0\ \forall G\in\mathcal G_{k,\Delta,R},
\quad
C_R(G)\ge 1
\Longrightarrow
\mu_R(G)\ge c_{k,\Delta,R}.
\]

\[
\mathbf{LCRB}:
\exists B_{k,\Delta,R}\ge 0\ \forall G\in\mathcal G_{k,\Delta,R},
\quad
\operatorname{TypeCount}_{k,R}(G)=1
\Longrightarrow
C_R(G)\le B_{k,\Delta,R}.
\]

\[
\boxed{
\text{Reduction status}=\text{locked}.
}
\]

\[
\boxed{
\text{Proof status}=\text{conditional on repository-native incompatibility between }
\mu_R(G)\ge c_{k,\Delta,R}
\text{ and }
\operatorname{TypeCount}_{k,R}(G)=1
\text{ for unbounded }C_R(G).
}
\]

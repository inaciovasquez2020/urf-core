# Proof Status

| Field | Value |
|---|---|
| Claim surface | URF Core |
| Status | Foundational logic / trusted base. |
| Scope | Minimal trusted base of definitions, axioms, theorems, schemas, and verification artifacts for the Unified Rigidity Framework. |
| Non-claim | This repository is not the full application layer for every downstream URF theorem. |

## Status discipline
- `Proved` = theorem-level claim closed inside declared scope.
- `Conditional` = depends on a named external hypothesis or unresolved lemma.
- `Executable` = build/test/verification surface closed without implying full theorem-level closure.
- `Experimental` = computational or exploratory artifact only.

# URF-11

## Status
OPEN

## Purpose
Create interaction across the 11 broad science-and-engineering fields by assigning:
- one anchor problem per field,
- branchable subproblems,
- bridge packets into other fields,
- acceptance tests for partial contributions.

## Canonical rule
Every accepted contribution must target either:
1. a field subproblem, or
2. a bridge packet from one field into another.

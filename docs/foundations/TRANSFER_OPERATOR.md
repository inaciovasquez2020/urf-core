# Transfer Operator

TRANSFER_OPERATOR_STATUS = CERTIFICATE_TRANSPORT_ONLY

THEOREM_CLOSURE = false

STATUS_PROMOTION_ALLOWED = false

BOUNDARY_PRESERVATION_REQUIRED = true

The Transfer Operator transports admissibility, boundary evidence, certificates, and invariant pullback data between URF surfaces.

It does not solve theorems.

It does not promote status.

It does not map frontier-open evidence to solved evidence.

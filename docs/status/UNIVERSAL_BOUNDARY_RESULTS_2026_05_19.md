# Universal Boundary Results

Status: `BOUNDARY_RESULTS_CLOSED`

This package closes three boundary results:

1. Weak tagged universal grammar existence:
   `TaggedUniversalRigidityGrammarExistence`

2. Unconditional universal translation from injective encoders alone is refuted:
   `not_unconditional_translation_from_injective_encoders`

3. A minimal vanishing-index obstruction to unrestricted UFEG is formalized:
   `UnrestrictedUFEG_vanishing_gap_obstruction`

The tagged grammar result is weak: it uses the dependent tagged sum
`Sigma Carrier`. It gives injective encoders and tagged predicate/relation lifts.

The unconditional translation result is negative: the Unit/Bool counterexample shows that injective encoders alone do not force code-preserving equivalence.

The unrestricted UFEG result is an obstruction surface: without a positive floor or compactness/finite-support/rate-thick/coercive restriction, a vanishing family defeats uniform floor claims.

configuration-pumping/cycle--orbit-splitting manuscripts.

finite FO$^k$ type counting is withdrawn.

types among an explicitly injected family of distinct configurations;
it does not force different vertex types. For maximum degree three and
radius one, the Petersen graph attains the maximal local cycle rank

at most six fails and any larger threshold is vacuous.

notation without a corresponding ordinary FO$^k$ variable-budget proof.
